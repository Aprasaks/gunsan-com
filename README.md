# GUNSAN.COM — 단계별 리빌드

현재는 **1단계: 헤더**만 구현했습니다.

- 로고: `public/brand/gunsan-wordmark.svg`
- PC / 노트북: 관광생생통 · 지역생생통 · 군산 이야기 · 검색창 (햄버거 없음)
- 모바일: 로고와 햄버거만 표시; 펼친 메뉴 안에 세 가지 메뉴와 검색창
- 닫기 버튼 / 배경 클릭 / Escape 키로 메뉴 닫기
- 준비되지 않은 페이지·검색은 안내 문구를 보여줌
- 메인 영역은 다음 단계에서 구현

로컬 실행: `npm install && npm run dev`

운영 원칙: 아직 방문하거나 검증하지 않은 장소·제휴 혜택을 실제 콘텐츠로 표시하지 않음.
