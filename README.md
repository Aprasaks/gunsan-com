# 군산닷컴 | GUNSAN.COM

군산의 모든 것을 담는 지역 기반 플랫폼. 현재는 관광객을 위한 **관광생생통**을 우선 개발합니다.

> 직접 다녀온 군산의 진짜 이야기를 바탕으로, 여행자에게 맞는 군산 여행을 제안합니다.

## 프로젝트 방향

- **군산닷컴 진입 화면:** 군산을 짧게 소개한 후 '지역생생통' 또는 '관광생생통'을 선택합니다. 약 5초 소개 연출을 구상하되 건너뛰기·재방문 UX를 고려합니다.
- **지역생생통:** 군산 거주자를 위한 지역 생활 플랫폼. 현재 기획·개발 보류.
- **관광생생통:** 직접 방문·검증한 여행 장소와 코스를 담는 **여행 매거진형 맞춤 관광 플랫폼**. 현재 최우선 개발 대상.

## 관광생생통의 운영 원칙

1. 직접 방문해 확인한 장소와 실제 경험에 기반한 콘텐츠만 정식으로 소개합니다.
2. 장점과 단점을 모두 공개하며 방문일·재확인일·제휴 여부를 분명히 기록합니다.
3. 글·사진·영상·쇼츠를 직접 제작하고 웹사이트와 SNS에 함께 활용합니다.
4. 초기에는 사전 검증된 여행 코스를 조건에 맞춰 추천하고, 데이터 축적 후 개인화 조합·AI 기능으로 발전시킵니다.
5. **선유도 유람선패스**를 첫 관광상품으로 구상하며, 지역 식당·카페 등과 제휴를 확대합니다. 실제 판매와 혜택은 계약·조건이 확정된 후 공개합니다.
6. 추천 콘텐츠의 평가 기준과 상업적 제휴·판매를 명확히 구분합니다.

## 메인페이지 콘셉트

**겉은 여행 잡지, 속은 맞춤 여행 플랫폼.**

- 잡지의 제호처럼 보이는 GUNSAN.COM 로고
- 군산 현장 사진이 중심인 편집디자인
- '이번 군산 여행은 어떤 모습인가요?' — 가족·연인·친구·혼자 여행 카드와 별도 **'군산 여행 추천받기' 카드**
- 직접 다녀온 군산 이야기
- 선유도 특집과 유람선패스
- 테마별 여행·검증 철학·하단 추천 CTA

메인 화면에 'AI' 표현을 전면에 내세우지 않습니다. 실제 여행자의 편의와 현장 검증의 신뢰를 우선합니다.
