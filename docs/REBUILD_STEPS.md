# GUNSAN.COM 단계별 리빌드

> **기본 디자인 기준:** 여행 매거진형 메인 시안. 메인 비주얼 → 여행 유형/추천받기 → 현장 취재 이야기 → 선유도 특집 순으로 하나씩 완성한다.

## 1단계: 헤더 (반영 완료)
- PC/노트북 높이 68px, 모바일 높이 60px
- PC: 로고, 관광생생통·지역생생통·군산 이야기, 검색창
- 모바일: 로고/햄버거만 표시, 검색은 펼친 메뉴 안에 포함

## 2단계: 메인 비주얼 + 여행 모습 카드 (현재 반영)
- PC 히어로 약 500px, 모바일 높이 조정
- 사진이 들어갈 영역과 문구의 좌우/상하 배치를 우선 확정
- 현장 촬영 사진이 아직 없으므로 `public/visuals/hero-concept.svg` 를 **명시적인 임시 콘셉트 비주얼**로 사용
- 실제 촬영 후 이 SVG를 사진으로 교체하고 모바일 별도 크롭을 결정
- 가족 / 연인 / 친구 / 혼자 / **군산 여행 추천받기** 총 5개 카드
- 카드 클릭 시 현재 기능 준비 중인 것을 안내하며, 미검증 코스를 생성하지 않음

## 3단계: 직접 다녀온 군산 이야기 (레이아웃 반영)
- `EDITOR'S PICK` + 제목 + 소개 문구 + 기사 자리 4개 (근대거리, 바다·섬, 맛집, 자연·트레킹)
- 카드 아트는 실사 대신 CSS 기반 편집용 비주얼. **실제 촬영 및 검증된 콘텐츠가 아님**을 표시
- 임의 날짜, 조회수, 리뷰, 방문 기록 미표기; 공개 가능 콘텐츠가 생기면 제목·이미지·리뷰·방문일 등을 교체
- 현재 전체 보기 링크는 미연결 안내만 표시, 실제 목록을 만든 후 활성화

## 4단계: 선유도 대표 특집 (현재 반영)
- 메인에서 ‘직접 다녀온 군산 이야기’ 아래 `SPECIAL ISSUE / SEONYUDO` 배치
- 유람선패스 기획 방향: **유람선 승선권 + 주변 식당 할인 + 카페 할인**
- ‘유람선패스 구성 살펴보기’ 버튼으로 기획 단계 안내를 펼쳐볼 수 있음
- ‘여행 유형부터 선택하기’로 맞춤 여행 영역 연결. 현재 선유도를 포함한 추천 자동화는 아직 없음
- 배경 `public/visuals/seonyudo-issue-concept.svg` 는 실물 운항선·정확한 해안 지형을 묘사한 사진이 아닌 **임시 일러스트**
- 상품 가격, 승선 시간, 제휴업체와 할인율은 미확정이므로 미표기
- 실제 촬영 사진과 계약된 제휴/이용조건이 확보될 때 교체

## 다음 단계 (아직 미구현)
1. 히어로 실제 사진 반영과 카피 최종 조정
2. 여행 유형 카드 실제 현장 사진 및 디테일 다듬기
3. 여행 조건 입력 및 검증 코스 추천 기능
4. 검증된 기사 실제 등록 및 목록/상세 페이지 연결
5. 선유도 특집의 실촬영 사진·취재 내용 및 실제 제휴/패스 판매 기능 연결

## 운영 원칙
- 실제 방문 확인 전에는 촬영·검증 완료 콘텐츠로 표시하지 않음.
- 실제 계약 전에는 제휴 혜택·판매 가능 상태로 표시하지 않음.
- 매 단계마다 GitHub 커밋 → Vercel 배포 → 화면 확인 후 다음 단계로 이동.


## 5단계: 나만의 군산 여행 추천받기 (입력 플로우 1차)
- 메인 여행 추천받기 카드를 `/recommend`로 연결 (다른 여행 유형 카드는 다음 차례)
- 데스크톱/모바일 대응 매거진형 진입 화면
- 3단계: ① 동행 형태·인원·아이 동반 ② 여행 기간·차량·숙박 ③ 관심 테마 1~3개
- 질문 누락 시 검증 문구, 이전·다음 이동, 결과 요약, 처음부터 다시 선택 제공
- 당일치기일 때 숙박 없음 자동 선택; 혼자 여행 선택 시 1명으로 설정
- 브라우저 안의 임시 화면 상태만 사용하며 여행 조건을 서버에 전송·저장하지 않음
- **검증된 코스 데이터 없음:** 실제 코스·업체·동선은 생성하지 않고 결과는 조건 요약과 준비 중 안내
- 관심사에 바다·섬이 포함될 때 실제 존재하는 메인 선유도 특집으로 이동 가능
- 추후 실제 취재 데이터 연결 후 추천 점수/규칙과 결과 페이지를 발전시킬 예정

## 6단계: 여행 추천받기 화면 리디자인 (간결한 매거진형)
- `/recommend`의 AI 설문처럼 보이는 큰 아이보리 패널, 사각 선택 카드, 3단계 마법사, 일러스트를 제거
- 흰 종이 기반 편집형 레이아웃, 세리프 타이틀·얇은 선·여백·라디오 선택 방식으로 전환
- 선택 항목을 **동행(혼자·친구·커플·가족) / 차량 유무 / 초등학생 동반 여부** 세 가지로 단순화
- 혼자 선택 시 초등학생 동반 없음으로 자동 설정; 모순 선택 방지
- 단일 화면에서 모든 항목 선택, 누락 안내, 조건 요약·다시 선택·선유도 특집 이동
- 장래 추천 기준 예고와 실제 검증된 코스의 결과를 구분하며 가상의 코스 추천 없음
- 입력 데이터는 일시적 클라이언트 상태만 사용하고 외부로 전송하지 않음
- 여행 기간·숙박·세부 취향 선택은 이번 1차 화면에서 제외 (추후 필요 시 추가)
