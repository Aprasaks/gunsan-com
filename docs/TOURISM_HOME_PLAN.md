# 관광생생통 메인페이지 통합 기획서 v1.0

- 프로젝트: **GUNSAN.COM / 관광생생통**
- 문서 성격: 기획 기준 문서 — 구현 완료 보고서 아님
- 작성 기준일: 2026-10-31
- 사업 맥락: 모두의 창업 로컬 트랙 1라운드 합격 후 2라운드 준비
- 일정 목표: 2026-11-30 전후 시연 가능한 1차 결과물
- 우선순위: **관광생생통 우선**, 지역생생통은 보류

## 1. 서비스 정의와 목표

**한 줄 정의:** 직접 다녀온 군산의 진짜 여행 정보를 바탕으로, 여행자에게 맞는 여행을 제안하는 로컬 여행 매거진형 플랫폼.

군산닷컴은 군산 지역의 모든 정보를 다루는 상위 브랜드이며, 이용 목적이 다른 두 화면 경험을 둡니다.

- **지역생생통:** 군산 거주자가 생활·사업장·지역 소식을 살피는 영역. 현재 범위 밖.
- **관광생생통:** 관광객이 군산을 발견하고, 여행을 계획하고, 검증된 콘텐츠를 읽고, 관련 관광상품을 탐색하는 영역. 독립적인 메인 디자인과 메뉴를 사용.

**사용자가 느껴야 할 가치:** '검색 결과를 뒤질 필요 없이, 실제로 다녀온 사람이 만든 군산 여행을 믿고 참고할 수 있다.'

### 핵심 원칙

1. 직접 방문한 장소만 정식 추천 데이터로 등록합니다.
2. 좋았던 점과 아쉬웠던 점을 함께 기록합니다. 정보는 경험과 사실을 구분해 전달합니다.
3. 직접 촬영한 사진·영상·쇼츠로 현장성을 증명합니다.
4. 장소만 나열하지 않고 여행 단위의 **코스**로 연결합니다.
5. 여행 인원·동행자·아이 동반·차량·숙박·선호 테마에 맞춘 코스를 제공합니다.
6. 초기 추천은 **검증된 사전 제작 코스 매칭**, 이후 데이터가 쌓이면 코스 조합과 개인화로 확장합니다.
7. 광고·협찬·상품 판매는 콘텐츠 평가와 분리하고 상업적 이해관계를 명확히 표시합니다.
8. 실제 계약이 없는 제휴 혜택, 실측하지 않은 소요 시간, 방문하지 않은 장소를 검증된 것처럼 표시하지 않습니다.

## 2. 사용자·경험

### 주요 사용자

- 군산을 당일치기·1박 2일·2박 3일로 방문하려는 관광객
- 가족(아이 동반 포함), 연인, 친구, 혼자 여행하는 여행자
- 뻔한 명소 외 새로운 군산을 찾는 재방문객
- 검증되지 않은 협찬성 추천과 반복되는 검색에 피로를 느끼는 여행자

### 핵심 방문 흐름

1. 군산닷컴 진입
2. 짧은 군산 소개 / 지역생생통·관광생생통 선택
3. 관광생생통의 매거진형 홈 도착
4. 여행 유형 카드 또는 '군산 여행 추천받기' 선택
5. 조건 입력 → 검증된 코스 추천 → 코스·장소 상세
6. 조건에 맞는 경우에만 선유도 유람선패스 등 관광상품 확인
7. 영상·현장 리뷰·유의사항을 보고 여행 결정

방문자가 코스를 만들지 않아도, 자유롭게 기사와 테마를 탐색할 수 있어야 합니다.

## 3. 브랜딩과 디자인 가이드

### 방향

- **관광 포털의 사용성 + 고급 여행 매거진의 편집 감성**
- 과한 기능 박스보다 큰 실사 사진, 편집형 타이포그래피, 충분한 여백
- 크림·웜화이트 계열 배경, 깊은 차콜 텍스트, 차분한 포인트 컬러
- 잡지 제호처럼 절제된 **GUNSAN.COM** 텍스트 로고
- 메인에 'AI 맞춤' 등 기술 중심 문구를 강조하지 않음

### 시각 언어

- 제목: 명확한 위계의 한국어 에디토리얼 타이포
- 본문: 읽기 편한 고대비 글자, 짧고 담백한 문장
- 사진: 실촬영을 우선. 가상·예시 이미지는 시안에만 쓰고 운영 콘텐츠처럼 제시하지 않음
- 카드: 둥근 박스의 과밀 배치보다 사진과 기사 제목의 균형
- 배너: 상품 소개도 'SPECIAL ISSUE'로 편집하되 가격·판매·제휴 표시를 숨기지 않음

### 카피 원칙

선호 예시:
- '시간이 여행이 되는 곳, 군산'
- '직접 다녀온 군산 이야기'
- '이번 군산 여행은 어떤 모습인가요?'
- '우리가 직접 다녀온 군산의 장소들로 당신에게 맞는 여행을 찾아드립니다.'

지양:
- 'AI가 분석한 최고의 여행'
- '빅데이터 기반 완벽한 추천'
- 과장된 1위·최고·인기 순위, 근거 없는 후기·조회수·방문 날짜

## 4. 정보 구조 (IA)

### 군산닷컴 진입 화면

- 브랜드 소개(약 5초 구상; 재방문 시 건너뛰기 옵션 고려)
- **지역생생통** 진입
- **관광생생통** 진입

### 관광생생통 주요 페이지

- 홈
- 여행 추천받기(조건 선택)
- 추천 결과 / 코스 상세
- 직접 다녀온 군산 이야기(기사 목록)
- 기사/장소 상세
- 테마별 여행 목록
- 선유도 특집 및 유람선패스 상세
- 검색 결과
- 운영 원칙·제휴 문의·정책 페이지

초기 메뉴 개수는 최소화합니다. 콘텐츠 부족 상태에서 빈 카테고리로 진입하지 않게 합니다.

## 5. 메인페이지의 전체 구성

순서가 중요한 기본 화면 구조:

1. 헤더
2. 히어로(대표 비주얼)
3. **'이번 군산 여행은 어떤 모습인가요?'** 여행 유형 4카드 + **추천받기 1카드**
4. **'직접 다녀온 군산 이야기'** 편집 기사
5. **'선유도를 제대로 즐기는 하루'** 선유도 특집 / 유람선패스
6. 테마별 군산 여행
7. 관광생생통의 검증 원칙
8. 하단 여행 추천 CTA
9. 푸터

**중요:** 맞춤 여행 설계가 서비스의 핵심 기능이므로 3번 섹션을 첫 스크롤 내 또는 직후에 노출합니다. 잡지형 감성만 강조하다가 추천받기 진입을 숨기지 않습니다.

## 6. 헤더 (Header)

### 구성

- 좌: **GUNSAN.COM**, 작은 부제 '군산, 그 이상의 여행' (확정 카피 아님)
- 중앙: 관광생생통(현재 활성) / 지역생생통 / 군산 이야기
- 우: 검색 진입, 전체 메뉴
- 로그인·마이페이지는 초기에는 노출하지 않으며, 계정 기능을 도입한 뒤 검토

### 행동

- GUNSAN.COM 클릭 → 상위 진입 화면 또는 관광생생통 홈(최종 URL 정책 확정 필요)
- 관광생생통 클릭 → 관광 홈
- 지역생생통 클릭 → 보류 영역 안내 또는 실제 서비스 출시 후 연결; 빈 페이지 금지
- 군산 이야기 클릭 → 검증된 콘텐츠 목록
- 검색 → 등록된 검증 장소·기사·코스 대상으로 검색
- 전체 메뉴 → 관광 콘텐츠·추천·패스·운영 정책 접근

### 반응형

- 데스크톱: 가벼운 가로 내비게이션, 일정 스크롤 이후 정돈된 고정형 헤더 가능
- 모바일: 브랜드 + 검색 + 햄버거 중심; 메뉴 열림/닫힘·접근성 고려
- 헤더가 사진의 중요한 부분을 가리지 않도록 배경 대비 확보

## 7. 히어로 (Hero)

**목적:** 군산에 대한 감정을 만들고 브랜드의 '현장성'을 처음 전달.

- 화면 폭을 활용하는 군산 대표 실사 사진(선유도, 근대거리, 바다 등)
- 작은 섹션 라벨: SPECIAL / GUNSAN STORY 등
- 메인 타이틀 예시: '시간이 여행이 되는 곳, 군산'
- 보조 문구 예시: '직접 다녀온 진짜 군산의 이야기'
- CTA는 1~2개로 절제: '군산 여행 추천받기', '군산 이야기 보기'
- 슬라이더 도입 시 자동 전환을 강요하지 않고 조작·정지 가능하게 설계
- 모바일용 사진 크롭과 텍스트 대비를 별도 검토

시안에 사용한 합성 사진이나 실제 방문 여부를 확인할 수 없는 이미지를 '직접 촬영' 콘텐츠로 표시하지 않습니다.

## 8. 여행 유형 + 추천받기 섹션 (최우선)

### 제목

**이번 군산 여행은 어떤 모습인가요?**

'우리가 직접 다녀온 군산의 장소들로 당신에게 맞는 여행을 찾아드립니다.'

### 카드 5개

| 카드 | 역할 | 이동/조건 |
| --- | --- | --- |
| 가족과 함께 | 가족·아이 동반 코스 탐색 | 가족 조건이 미리 선택된 추천 화면 |
| 연인과 함께 | 여유로운 둘만의 여행 | 연인 조건이 미리 선택된 추천 화면 |
| 친구와 함께 | 활동·식도락·사진 등 | 친구 조건이 미리 선택된 추천 화면 |
| 혼자 여행 | 산책·고요한 장소 등 | 혼자 조건이 미리 선택된 추천 화면 |
| **군산 여행 추천받기** | 일반 맞춤 추천의 대표 진입점 | 조건 선택 화면으로 이동 |

추천받기 카드는 다른 네 카드와 대비되는 편집형 배경·문구·화살표로 강조하지만, 전형적인 앱 배너처럼 과장하지 않습니다.

### 추천 플로우 — MVP

입력 후보:
- 여행 기간: 당일치기 / 1박 2일 / 2박 3일
- 여행 인원
- 동행 형태: 가족·연인·친구·혼자·기타
- 아이 동반 여부(필요 시 나이대)
- 차량 보유 / 대중교통
- 숙박 여부
- 선호 테마: 바다·섬, 근대역사, 맛집·카페, 자연·트레킹, 체험 등
- 선택 확장: 이동 강도·예산·출발 지역·여행 날짜

**초기 추천 알고리즘:** 직접 검증하고 미리 확정한 코스에 태그를 붙여 조건 일치도를 계산한 후 상위 코스를 추천합니다. 'AI 생성'이라는 표현은 사용하지 않습니다.

**결과에 필수로 표시할 것:**
- 코스명, 대상, 기간
- 추천 이유와 주요 동선
- 방문 순서, 대략적인 체류·이동 시간(실측 또는 명확한 추정 표시)
- 연결된 검증 장소·기사·영상
- 주차·아이 동반·교통·휴무·날씨 유의사항
- 근처 식당·카페·숙소(직접 검증된 경우에만)
- 선유도 패스 등 관련 상품(실제 해당 코스와 관련 있을 때만)

**결과 없음 처리:** 조건에 정확히 맞는 코스가 없으면 검증하지 않은 장소를 생성하지 않습니다. '현재 검증된 코스가 부족합니다'를 알리고 조건을 완화하거나 확인된 유사 코스를 제안합니다.

## 9. '직접 다녀온 군산 이야기' 섹션

**목적:** 관광생생통의 신뢰 자산을 콘텐츠로 체감시키기.

- 제목: '직접 다녀온 군산 이야기'
- 보조 설명: '발로 뛰고, 보고, 먹으며 기록한 군산의 진짜 여행 이야기입니다.'
- 유형: 관광지, 맛집, 카페, 숙소, 걷기·트레킹, 체험, 영상 취재
- 노출: 편집자가 고른 실제 발행 기사 3~4개부터 시작
- 카드: 실사진 / 카테고리 / 제목 / 짧은 미리보기 / 실제 방문일(있는 경우)
- 더 보기 → 기사 목록
- 검증되지 않은 조회수·후기·인기 표시를 만들지 않음

### 기사/장소 상세 템플릿

- 제목·한 줄 소개
- 직접 촬영한 대표 사진과 영상/쇼츠
- 방문일 / 마지막 정보 확인일
- 관찰한 특징과 실제 경험
- **좋았던 점 / 아쉬웠던 점**
- 추천 대상 / 추천하지 않을 수 있는 대상
- 위치, 주차, 접근성, 아이 동반, 영업·운영 정보(출처 및 확인일)
- 비용, 예약·휴무, 날씨 관련 유의사항
- 검증한 다른 주변 장소 또는 코스 링크
- 협찬·제휴·광고·수익 관계 표시
- 폐업/변경 사항 제보 및 수정 절차(향후)

## 10. '선유도를 제대로 즐기는 하루' 특집

**목적:** 여행 매거진의 특집 기사로 선유도를 소개하고, 관련 관광상품을 자연스럽게 연결.

### 화면 표현

- 큰 선유도 실사 사진
- 작은 라벨: SPECIAL ISSUE
- 제목: '선유도를 제대로 즐기는 하루'

## 19. 화면별 수용 기준 (Definition of Done)

2. '군산 여행 추천받기'에서 조건을 입력하면 존재하는 검증 코스가 결과로 나옵니다.
3. 매칭 결과가 없을 때 빈 화면·가상 데이터가 아니라 안내와 대안 행동이 제공됩니다.
4. 편집 기사 카드에서 실제 상세 페이지·사진·장단점·방문일을 확인할 수 있습니다.
5. 선유도패스 영역은 사업 진행 단계에 맞게 판매 가능/준비 중 상태를 정확하게 보여줍니다.
6. 메뉴·CTA·뒤로 가기·모바일 내비게이션이 모두 작동합니다.
7. 테스트용 허위 리뷰, 허위 조회수, 실재하지 않는 제휴 혜택은 공개하지 않습니다.
8. 모바일 기본 해상도에서 가로 넘침, 글자 가림, 클릭 불가 요소가 없어야 합니다.
9. 개인정보가 수집되면 목적·보관·삭제 기준과 고지 동의 절차를 먼저 마련합니다.

## 20. 실제 사업화 및 2라운드 검증

### 1라운드 기획과의 연결

- 기존 군산패스 아이디어를 **선유도 유람선패스**라는 첫 번째 구체적 상품으로 좁힙니다.
- 기존 '코스로 추천'을 **여행 유형 → 조건 선택 → 검증 코스 추천**의 작동 흐름으로 구체화합니다.

- 콘텐츠, 제휴, 관광객 소비를 연결하는 로컬 사업 모델이라는 일관성을 유지합니다.

- 실제 관광객이 추천 플로우를 끝까지 사용하는가?
